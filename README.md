📝 To-Do List App

A simple and user-friendly To-Do List application built using HTML, CSS, and JavaScript. It helps users organize daily tasks, track completed work, and manage their activities efficiently.

✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🎨 Hover effects for interactive buttons
- 💾 Save tasks using browser Local Storage
- 🔄 Retain tasks after refreshing the page
- ⌨️ Add tasks by pressing the Enter key
- 📱 Simple and responsive user interface

🛠️ Technologies Used

- HTML5 — Structure of the application
- CSS3 — Styling, layout, and animations
- JavaScript — Task management and interactivity
- Local Storage — Save tasks in the browser
